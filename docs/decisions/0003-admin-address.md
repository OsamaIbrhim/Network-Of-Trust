# 0003: عنوان الـ admin في العقد

- **التاريخ:** 2026-09-28
- **الحالة:** مقبول
- **المرحلة:** Phase 1 (قبل Task 6)

## السياق (Context)
عنوان واحد (`DEFAULT_ADMIN_ROLE`) بيعتمد الجامعات، ويضيف ويشيل المحافظ، ويوقف ويشغّل العقد. والعقد مش قابل للتعديل. لو الـ constructor اتنادى بـ `address(0)` بالغلط، العقد يطلع من غير admin ومحدش يقدر يعتمد أي جامعة عليه، وساعتها لازم يتنشر من جديد.

## البدائل (Options)

| المعيار | أ: نرفض `address(0)` بس، ونثبت إن الـ admin ينفع يتنقل | ب: نرفض 0 + `AccessControlDefaultAdminRules` (نقل على خطوتين بفترة انتظار) | ج: نسيبه زي ما هو |
|---|---|---|---|
| الصحة والأمان | بيمنع الغلطة الأخطر، والنقل لـ multisig ممكن ومتختبر | أأمن ضد النقل لعنوان غلط، بس مش بيحمي من سرقة المفتاح | العقد ممكن يتنشر من غير admin |
| البساطة | سطر واحد + اختبار | تغيير في الـ interface والـ deploy والاختبارات | من غير تغيير |
| التكلفة | تقريبًا صفر | أكبر، ومفيش فايدة حقيقية على testnet | صفر |

## القرار (Decision)
البديل أ: `if (admin == address(0)) revert InvalidAdmin();`، واختبار بيعمل نقل للـ admin لعنوان جديد (`grantRole` بعدها `renounceRole`) ويتأكد إن القديم خسر الصلاحية.

## ليه (Rationale)
الحماية الحقيقية لمفتاح الـ admin هي إنه يبقى **multisig**، يعني محفظة محتاجة توقيع أكتر من شخص، مش فترة انتظار. والنقل لـ multisig ممكن من غير تعديل العقد، والاختبار بيثبت كده.

## التمن (Consequences)
على Sepolia، الـ admin محفظة واحدة. وقبل أي نشر حقيقي، لازم يتنقل لـ multisig (مكتوبة في ARCHITECTURE قسم الأمان).

## هنعرف إزاي إننا غلطنا
لو احتجنا نحمي نفسنا من نقل الـ admin بالغلط لعنوان غلط. وقتها البديل ب يتعمل في عقد جديد.
